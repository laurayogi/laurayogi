## Circlemakers Brand Hub
**An MCP server that makes our brand guidelines readable by AI tools**

Brand guidelines usually live in a PDF that people rarely open and AI tools never see. I wanted our brand available inside every tool the team uses, so work starts on-brand instead of being fixed afterwards.

- **What it does:** Claude and Lovable can pull Circlemakers' colors, typography, voice and tone, and services on demand, and check any color against our palette.
- **Tools:** MCP (Model Context Protocol), Claude, Lovable
- **Status:** In use at Circlemakers. Now selling the same setup to clients.
- **Link:** [Visit the Brand Hub](https://cs-brand-connector.lovable.app/)

## LinkedIn & Substack voice skill
**A Claude skill that writes in my voice**

A skill is a set of reusable instructions Claude follows every time. Mine holds my voice, my content pillars, the post formats that work for me, and a list of phrases I never want to see (including the usual AI tells). I give it my first drafts, voice memos or event notes from Granola, and get back edits that sound like how I write.

- **Why it matters:** brand voice drifts slowly as teams and AI tools pull it in different directions. Voice guidelines that an AI can follow work as a brand operating system, and I use the same approach with clients.
- **Tools:** Claude Skills
